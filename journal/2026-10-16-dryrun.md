The snapshot exists (`portfolio/2026-10-16-dryrun.json`, written in step 1). The cause is in `strategy/current.py` `main()`: it calls `portfolio.latest_state(date.today())` with the default `dry_run=False`. `latest_state` deliberately shows live runs only live snapshots and dry runs only dry-run snapshots, so with `dry_run=False` it ignores every `-dryrun` file and finds nothing. Two smaller issues on the same line: it uses `date.today()` (machine clock, 2026-10-18) instead of `finance.clock.today()` (the replayed 2026-10-16), and so would also miss the exact-date lookup in a replay and rely on the newest-file fallback. The unit tests presumably call `generate()` directly, which is why this was not caught. I did not edit `strategy/current.py`: the daily session may not change the algorithm file, and a fix belongs to the owner or the research session. I also tried to compute only the read-only signals (trend filter, ranking) from a scratch script outside the repo; the hooks forbid writes outside the repo and the sandbox denied running it, so there is no signal output today either.
